# NaviSense (Flutter)

UI for a smart indoor navigation app concept for malls.

## Screens
Splash, onboarding, login/register, home, QR scan, AR-style navigation,
destination list, route, find friend, search history, profile, admin panel.

## Tech
Flutter, Dart

## Status
UI prototype. QR scanning, AR, and backend are not connected yet.

## Run
flutter pub get
flutter run
